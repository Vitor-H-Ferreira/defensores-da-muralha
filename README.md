## 🏯 A história

Os invasores se aproximam. Você é um guardião da Grande Muralha da China e a única forma de avançar é abrir os portões, e cada portão é trancado por um enigma de matemática.

Acertou, o portão se abre e você segue adiante. Errou, perde uma vida, mas aprende a resposta certa. Chegue à **torre final** para defender toda a muralha.

---

## 🎮 Como jogar

| Ação | Tecla ou botão |
|:--|:--|
| Andar pela muralha | `←` `→` ou `A` `D` (botões ◀ ▶ na tela) |
| Desafiar um portão | `E` ou botão **Interagir** |
| Escolher a resposta | Clique na alternativa, ou teclas `1` a `4` |
| Pausar o jogo | `Esc` |

### 🏆 Pontuação

| Evento | Resultado |
|:--|:--|
| Resposta correta | **+100** pontos |
| 3 acertos seguidos | **+200** de bônus |
| Resposta errada | Perde 1 das **3 vidas** e vê a explicação |
| Chegar à última torre | Vitória, com pontuação final e estrelas |

---

## 📜 O que você vai praticar

São **10 portões** com dificuldade crescente. Cada portão tem mais de uma pergunta, para variar a partida.

| Portões | Tema |
|:--:|:--|
| 1 a 3 | Adição e subtração |
| 4 | Multiplicação |
| 5 | Divisão |
| 6 | Porcentagem |
| 7 | Frações |
| 8 | Perímetro |
| 9 | Área |
| 10 | Geometria e proporção |

## 🛠️ Para desenvolvedores

Abra o `index.html` em qualquer navegador moderno. Não há build nem dependências. As fontes vêm do Google Fonts.

Para criar novas perguntas, edite a lista `NIVEIS` no início do script. Cada pergunta segue este formato:

```js
{
  p:   'Um trecho da muralha possui 120 metros. Os guardas já protegeram 75 metros. Quantos metros ainda faltam?',
  ok:  '45 metros',
  err: ['35 metros', '55 metros', '65 metros'],
  exp: 'Subtraia o que já foi protegido do total: 120 − 75 = 45 metros.'
}
```
